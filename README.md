# Guia Prático de Git e GitHub

Este repositório foi desenvolvido como parte de uma atividade acadêmica com o objetivo de compreender e documentar o ciclo de vida de um projeto utilizando Git e GitHub.

## Objetivo

Apresentar os principais conceitos e práticas relacionados ao versionamento de código, desde a criação de um repositório até o gerenciamento de atualizações.

## Conteúdo da Atividade

O documento está dividido em três partes:

### 1. Criação e Envio de um Projeto
- Criação de um repositório no GitHub.
- Inicialização do Git em uma pasta local.
- Conexão entre o repositório local e o remoto.
- Realização do primeiro commit e push.

### 2. A Importância do README.md
- Finalidade e público-alvo da documentação.
- Informações essenciais de um README profissional.
- Utilização da linguagem Markdown.

### 3. Atualizações no GitHub
- Atualizações diretamente pelo navegador.
- Utilização do Git pelo terminal.
- Integração com o VS Code.
- Utilização do GitHub Desktop.
- Importância dos commits frequentes.

## Ferramentas Abordadas

- Git
- GitHub
- Visual Studio Code
- GitHub Desktop
- Markdown
